02 / ROUTE PLANNING

Find the shortest route.

Dijkstra finds a shortest path from a start node in a graph with non-negative edge weights.

DIJKSTRA'S ALGORITHM
TIME O((V + E) log V)SPACE O(V + E)
DIJKSTRA RESULT
Choose two locations and run Dijkstra.
How it works +
  1. Start at the source with distance 0.
  2. Choose the nearest unvisited node and relax its roads.
  3. Repeat, then reconstruct the route.
03 / NETWORK CONSTRUCTION

Connect the locations.

Kruskal builds a minimum spanning tree by adding the lightest edges that do not create a cycle.

KRUSKAL'S ALGORITHM
TIME O(E log E)SPACE O(V + E)

Use Union-Find to connect all five locations with the smallest total road weight.

MINIMUM SPANNING TREE
Generate the tree to see the selected roads.
How it works +
  1. Sort all roads by weight.
  2. Add a road if its endpoints are not already connected.
  3. Repeat until all locations are connected.
04 / STATION PLACEMENT

Make the budget count.

0/1 knapsack chooses the highest-benefit combination within the budget. Each candidate can be chosen at most once.

0/1 KNAPSACK
TIME O(nW)SPACE O(nW)W is the budget in cost units after scaling by the GCD of candidate costs.

Checked stations are candidates, not automatically selected.

RECOMMENDED STATIONS
Choose candidates and run the optimizer.
How it works +
  1. Build a DP table: rows are stations and columns are budget units.
  2. For each station, compare excluding it with including it once.
  3. Backtrack to recover the selected stations.

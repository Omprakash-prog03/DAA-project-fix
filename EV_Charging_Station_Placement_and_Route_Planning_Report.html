Abstract

This report documents the design and implementation of an EV Charging Station Placement and Route Planning System. The system models road networks as weighted graphs and utilizes Kruskal's Minimum Spanning Tree for network analysis, 0/1 Knapsack Dynamic Programming for budget-constrained station selection, and Dijkstra's Shortest Path for route calculation. The application integrates real-world data sources and provides a professional product-grade UI/UX interface.
